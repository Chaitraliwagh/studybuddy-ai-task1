# Demo script (about 2 minutes)

## Before recording

1. Start Ollama, the backend and the frontend (see README).
2. Open <http://localhost:5173>. The header should show `gemma3:4b ready`.
3. Do one dry run first, because the first request loads the model and is slower. Don't record that one.
4. Close other apps and notifications. Use a browser window of about 1280 px width.

## Flow

1. **Open StudyBuddy AI.** Say who it's for: "I built this for a friend who finds long study material hard to follow."
2. **Paste notes.** Click *Try sample notes* (or paste your own), then **Save notes**.
3. **Explain Simply.** Click the card and let the result load.
4. **Ask AI.** Ask: *What are the four conditions for deadlock?* Then ask something not in the notes, for example *Who created Linux?*. Check beforehand that the answer says it isn't in the notes. A small model may not always follow that instruction, so only show it if it works.
5. **Summarize.**
6. **Generate Quiz.** Answer two questions to show the feedback and explanations.
7. **Create Revision Plan.**
8. Close by saying the AI is Gemma running locally through Ollama, so notes stay on the computer.

## Recording tips

- Windows: Xbox Game Bar (Win + G) or OBS. macOS: Shift + Cmd + 5. Linux: OBS.
- If model responses are slow, trim the waiting in a video editor, and say so in the description if you do.
- Upload to YouTube (unlisted) or attach the file in your DEV post, then paste the link in `HACKTOBERFEST_SUBMISSION.md`.
